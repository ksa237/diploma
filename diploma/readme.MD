# Описание функционала серверной части приложения "Облачное хранилище"

Серверная часть приложения представляет собой выполнения ряда функций, вызов которых осуществляется клиентом (браузером пользователя)
при переходе на опеределенные "эндпойнты", т.е. пути в строке браузера, оканчивающиеся на заданные "ключи"

Также на вызов той или иной функции приложения влияет тип запроса клиента браузера (GET, POST, PUT и т.д.)

Всю функциональность по вызову функций данного серверного приложения берет на себя клиентская чать (front-end), которая представлена отдельным приложением,
выполняющемся в браузере клиента и реализованная на платфформе node.js. Описание установки и работы с клиентской частью не входит в данную документацию.

Все вызовы серверных функций можно разделить на группы:

1. аутентификация пользователя
2. работа с файлом
3. содержимое облачного хранилища пользователя

Первая группа содержит такие эндпойнты:
  - /login
  - /logout

Вторая группа содержит:
  - /file

Третья группа
  - /list

Полное техническое описание функций серверного приложения см. по ссылке. [Документация API](https://github.com/netology-code/jd-homeworks/blob/master/diploma/CloudServiceSpecification.yaml) 

## Технологии и методы

Данное приложение представляет собой RESTfull-приложение.
В качестве средства идентификации пользователя использует пару: логин + пароль, а также токен-авторизации, которые используется каждый раз при вызове функций
после единого успешного сеанса авторизации в начале работы с приложением.

Данные о пользователях, в том числе авторизационные данные храняться в надежной СУБД PostgreSQL.
Все данные облачного хранилища также храняться в СУБД PostgreSQL.

## Запуск и использоввние

Для работы с серверной частью приложения необходимо установить и запустить клиентсткую часть. см. отдельную документацию.
